================================================================================
QUICK SETUP STEPS
================================================================================

1. Deploy Terraform (15-20 min)
   cd terraform/environments/dev
   terraform init -backend-config=...
   terraform plan
   terraform apply

2. Configure Kubernetes (5 min)
   aws eks update-kubeconfig --name microservices-dev-eks
   kubectl create secret generic db-credentials

3. Configure GitHub (5 min)
   Set secrets: AWS_ACCOUNT_ID, AWS_ROLE_TO_ASSUME, EKS_CLUSTER_NAME_*

4. Deploy Helm Charts (2 min)
   helm install microservices-app ./helm --values helm/values-dev.yaml

5. Test Pipeline
   git push origin develop
