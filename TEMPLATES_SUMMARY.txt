QUICK COMMANDS
================================================================================

Build images:
  gh workflow run build-image.yml
  gh workflow run build-image.yml -f service=user-service

Plan infrastructure:
  gh workflow run deploy-infra.yml -f environment=dev -f action=plan

Apply infrastructure:
  gh workflow run deploy-infra.yml -f environment=dev -f action=apply

Deploy application:
  gh workflow run deploy-app.yml \
    -f environment=dev \
    -f user-service-tag=abc1234 \
    -f order-service-tag=abc1234

Monitor workflow:
  gh run watch <run-id>
  gh run view <run-id> --log

TROUBLESHOOTING
================================================================================

Workflow won't trigger?
  - Check branch protection rules
  - Verify trigger conditions
  - Check workflow file syntax

OIDC authentication fails?
  - Verify OIDC provider in AWS
  - Check IAM role trust policy
  - Verify secret value

Terraform fails?
  - Check tfvars file
  - Verify backend bucket exists
  - Check AWS credentials

Helm deployment fails?
  - Verify cluster accessible
  - Check database credentials secret
  - Verify RDS endpoints
